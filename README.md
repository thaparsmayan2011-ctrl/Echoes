# Echoes
It is a puzzle game.

 Echoes

Echoes is a puzzle game where you use recordings of your previous runs to navigate challenges.

How to Play
Arrow Keys – Left and right
Space – Jump
E – Record an Echo of your current run and restart
R – Restart the level

 Objective
Use your Echoes to activate buttons, open doors, and reach the exit. 

Built With
 HTML
 JavaScript
 HTML Canvas

 Demo link
 https://echoes-tawny-delta.vercel.app/

 How to download
 Download from the git repository and extract all files.

 Run the Game
